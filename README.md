# Анк-Морпорк — веб-версия

Браузерная версия настольной игры «Плоский мир: Анк-Морпорк» для игры с друзьями.

## Запуск у себя

```
npm install
npm run play      # http://localhost:3001
```

Разработка: `npm run dev:server` и `npm run dev:client` (http://localhost:5173).
Тесты движка: `npm test`.

## Игра по сети

Задеплойте на Render (файл `render.yaml`) или откройте локальный сервер наружу:
`ngrok http 3001`. Создайте игру, скопируйте ссылку и отправьте друзьям.

На бесплатном плане Render сервер засыпает после ~15 минут простоя, партии хранятся в памяти.

## Что автоматизировано (веха 1)

Ходы, символы карт (слуга, здание, убийство, беспорядок, деньги, событие, «сыграть ещё»),
беспорядки, контроль, условия победы, финальный подсчёт, отмена в пределах хода.
Тексты карт, способности районов и эффекты событий выполняются вручную через «✋ Ручной режим».

Цены дорогих районов — $18, как в оригинале (на поле русского издания напечатано $17).

## Ассеты

Исходники (PDF, PSD, таблица перевода, шрифт) лежат в `source/` и не коммитятся.
Пересборка картинок:

```
python tools/assets/build_cards.py
python tools/assets/build_board.py
python tools/assets/build_tokens.py
```

Разметка районов на поле правится в браузере: `#/dev/areas`.

## Проверки в браузере

Скрипты на puppeteer (сервер должен быть запущен через `npm run play`):

- `node scripts/net-test.mjs http://localhost:3001` — создание игры и вход второго игрока;
- `node scripts/secrecy-test.mjs http://localhost:3001` — чужие карты и колода не уходят по сети;
- `node scripts/hotseat-test.mjs http://localhost:3001` — партия в хотсите до победы;
- `node scripts/shot.mjs <url> <файл.png>` — скриншот (размер окна: переменные `W`, `H`).

Если puppeteer не находит Chrome, укажите путь через `PUPPETEER_EXECUTABLE_PATH`.
