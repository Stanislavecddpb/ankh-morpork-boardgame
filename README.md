# Анк-Морпорк — веб-версия

Браузерная версия настольной игры «Плоский мир: Анк-Морпорк» для игры с друзьями.

## Запуск у себя

```
npm install
npm run play      # http://localhost:3001
```

Разработка: `npm run dev:server` и `npm run dev:client` (http://localhost:5173).
Тесты движка: `npm test`.

## Игра по сети

Задеплойте на Render (файл `render.yaml`) или откройте локальный сервер наружу:
`ngrok http 3001`. Создайте игру, скопируйте ссылку и отправьте друзьям.

Партии сохраняются на диск (папка `data/matches`, или переменная `MATCHES_DIR`) и переживают перезапуск сервера;
закрытая вкладка возвращает игрока на его место по той же ссылке. На бесплатном плане Render диск временный:
после засыпания сервера (~15 минут простоя) партии пропадают.

Хост начинает игру, когда все заняли места. Когда нужно ваше действие, у вкладки появляется «● Ваш ход»
(и короткий звук, если окно не в фокусе). Изменившиеся районы на поле на несколько секунд подсвечиваются.
Если игрок отошёл и не отвечает на вопрос карты или прерывание, через 30 секунд у ходящего появляется
кнопка «Ответить за …» (выбирается самый безобидный вариант).

## Что автоматизировано

Ходы, символы карт (слуга, здание, убийство, беспорядок, деньги, событие, «сыграть ещё»),
беспорядки, контроль, условия победы, финальный подсчёт, отмена в пределах хода.
Тексты всех 70 карт со свитком: игрок ведётся по шагам, соперник отвечает сам на своём экране
(в хотсите — после передачи компьютера). Скрытое (чужие руки, неиспользованные личности) видит
только тот, кому положено.

Способности карточек районов: кнопки в панели действий (или клик по светящейся карточке у игрока);
Мелкие Боги сами предлагают защиту при событиях. Все 12 случайных событий разыгрываются автоматически:
кубики бросаются сразу, игроки сами решают, куда увести слуг от наводнения, кого убрать в убийствах,
какие здания снести при обрушении.

Прерывания: если чужое убийство, текст карты или событие (Дракон, Тупица Джонсон, Таинственные убийства)
убрали или передвинули вашего слугу, а у вас на руке Гаспод, Сьюзан, Клуб «Начни заново», Игорь или
Уоллис Сонки, игра предложит сыграть карту (Сонки — и когда вас выбрали целью текста карты). Доктор Мосси Лаун
и любое прерывание «вне очереди» — кнопками под рукой.

Вручную через «✋ Ручной режим» (он умеет всё: фишки, деньги, карты между зонами, события,
личности, карточки районов, конец игры) — любые исправления и редкие случаи.

Цены дорогих районов — $18, как в оригинале (на поле русского издания напечатано $17).

## Ассеты

Исходники (PDF, PSD, таблица перевода, шрифт) лежат в `source/` и не коммитятся.
Пересборка картинок:

```
python tools/assets/build_cards.py
python tools/assets/build_board.py
python tools/assets/build_tokens.py
```

Разметка районов на поле правится в браузере: `#/dev/areas`.

## Проверки в браузере

Скрипты на puppeteer (сервер должен быть запущен через `npm run play`):

- `node scripts/net-test.mjs http://localhost:3001` — создание игры и вход второго игрока;
- `node scripts/net-play.mjs http://localhost:3001 4` — полная сетевая партия: 4 отдельных браузера, перезагрузки
  посреди партии, двойные клики, сверка лога у всех и проверка, что никому не приходят чужие руки и колода;
- `node scripts/secrecy-test.mjs http://localhost:3001` — чужие карты и колода не уходят по сети;
- `node scripts/hotseat-test.mjs http://localhost:3001` — партия в хотсите до победы;
- `node scripts/scroll-test.mjs http://localhost:3001` — хотсит на троих: свитки, районы, события, прерывания, ответы на все виды вопросов;
- `node scripts/shot.mjs <url> <файл.png>` — скриншот (размер окна: переменные `W`, `H`).

Если puppeteer не находит Chrome, укажите путь через `PUPPETEER_EXECUTABLE_PATH`.
