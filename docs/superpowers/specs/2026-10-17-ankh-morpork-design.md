# «Плоский мир: Анк-Морпорк» — веб-версия. Дизайн

Дата: 2026-10-17

## Цель

Перенести настольную игру «Плоский мир: Анк-Морпорк» (Мартин Уоллес, 2–4 игрока)
в браузер, чтобы играть с друзьями по ссылке. Используются собственные материалы:
русские карты (PDF для печати), поле и жетоны (`для_распечатки.pdf`), правила,
FAQ, таблица перевода, шрифт FolkardCyr.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Стек | Как в «Кикладах» (`../ancient-greece`): boardgame.io 0.50, React 18, Vite, Koa + socket.io, TypeScript, npm workspaces, деплой на Render |
| Переиспользование | Копируем «Киклады» как шаблон и убираем игровую логику. Общий пакет не выносим |
| Автоматизация | Гибрид: базовые правила автоматически, тексты карт подключаются постепенно; до этого работает ручной режим |
| Поле | Склеиваем оригинальный скан, поверх кладём SVG-зоны районов |
| Ручной режим | Доступен только активному игроку (или игроку, от которого ждут реакции) + отмена в пределах хода |
| Платформа | Десктопный браузер, ширина от 1366 px. Мобильная вёрстка — не цель |

## 1. Архитектура и ассеты

```
ankh-morpork/
  packages/engine   — правила на boardgame.io: состояние, фазы, ходы, эффекты карт; тесты на vitest
  packages/server   — Koa + socket.io из «Киклад», раздаёт собранный клиент
  packages/client   — React + Vite: лобби (из «Киклад»), стол, рука, лог
  tools/assets      — Python-скрипт (pymupdf, Pillow): PDF → веб-картинки
  source/           — исходные материалы (PDF, PSD, xlsx, шрифт); в .gitignore
```

Из «Киклад» без изменений или почти без них переносятся `server/src/index.ts`,
`client/src/{App,Home,GameRoom,LocalGame,net}.tsx/ts`, `render.yaml`,
`scripts/net-test.mjs`, `scripts/shot.mjs`, `tsconfig.base.json`, структура
корневого `package.json`. Всё игровое пишется заново.

**Конвейер ассетов** (`tools/assets/build.py`, запускается вручную, результат коммитится):
- Каждая карта из `ForPrint/**.pdf` → `packages/client/public/cards/<deck>/<id>.webp`
  (районы, события, личности, зелёная и коричневая колоды, рубашки).
- Поле: страницы с фрагментами поля из `для_распечатки.pdf` склеиваются в
  `public/board.webp` (координаты стыков подбираются один раз и хранятся в скрипте).
- Жетоны (миньоны и здания 4 цветов, беспорядок, демон, тролль, монеты $1/$5)
  вырезаются из тех же страниц в `public/tokens/*.webp`.
- Скрипт проверяет: число вырезанных карт совпадает с каталогом, у каждой записи
  каталога есть картинка.
- Объём в git — порядка 10–20 МБ; исходники (~370 МБ) в git не попадают.

Названия карт берутся из `Ankh-Morpork Translation sheet.xlsx`, число копий — из
префикса имени PDF-файла (сверяется с таблицей). Текст эффекта игрок читает на
картинке карты; в данных он не дублируется.

Шрифт FolkardCyr используется для заголовков интерфейса.

Деплой — как у «Киклад»: Render free plan (засыпает после простоя, партии в
памяти), запасной вариант — локальный сервер + ngrok. Ссылка публична: картинки
карт доступны любому, кто её знает; для игры с друзьями это приемлемо.

## 2. Движок: состояние и ход

**Состояние `G`:**
- `areas[1..12]`: миньоны по игрокам, здание (владелец), жетон беспорядка,
  число демонов и троллей. Соседство (общая граница или мост) — статическая таблица.
- `players[id]`: деньги, займы, рука, полученные карты районов, личность
  (скрыта), запас миньонов (12) и зданий (6), цвет.
- Колоды: игровая (перемешанная зелёная поверх перемешанной коричневой), события,
  сброс, карты, лежащие перед игроками по тексту карт.
- `pending`: текущее незавершённое действие (очередь символов разыгрываемой
  карты, ожидаемый выбор, ожидаемая реакция другого игрока).
- `log`: человекочитаемый лог, общий для всех.

**Скрытая информация** — через `playerView`: игрок видит свою руку и личность;
о других — только число карт в руке; о колодах — только размер. Перемешивание
и броски кубика — через `random` boardgame.io (на сервере).

**Подготовка:** по одному миньону каждого игрока и по жетону беспорядка в
Тенях, Сточном районе и Сёстрах Долли; по $10 каждому; раздача личностей и 5 карт;
первый игрок — бросок кубика. Для 2 игроков: убрать Хризопраза из личностей,
Хьюберта и Космо Роскошь из игровых карт.

**Ход:**
1. В начале хода проверяется условие победы текущего игрока. Выполнено → конец
   игры, личности раскрываются.
2. Игрок играет карту. Символы выполняются слева направо; любой можно пропустить,
   кроме случайного события. Символы:
   - миньон, здание, убийство, снятие беспорядка, деньги, случайное событие,
     «сыграть ещё одну карту» — автоматизированы;
   - свиток (текст карты): если у карты есть реализованный эффект — движок ведёт
     игрока по выборам; иначе включается ручной режим и кнопка «Готово».
3. Конец хода: добор до 5 карт (лишние не сбрасываются). Колода закончилась →
   побеждает Ваймс (если он в игре), иначе подсчёт очков: $5 за миньона,
   стоимость зданий, деньги, минус займы.

**Базовые правила, которые соблюдает движок:**
- Миньон ставится в район со своим миньоном или в соседний с ним; если все 12 на
  поле — можно переставить своего.
- Беспорядок появляется, когда миньон входит в район, где уже есть миньон;
  снимается, когда из района убирают любую фишку-миньона (в т.ч. демона/тролля).
- Здание: свой миньон в районе, нет беспорядка, район свободен от зданий, оплата
  цены; игрок получает карту района.
- Убийство — только в районе с беспорядком.
- Контроль района: фишек (миньоны + здание) больше, чем у любого другого игрока
  по отдельности, больше, чем троллей, и нет демонов.
- Способности карт районов — не чаще раза в ход.
- Условия победы личностей (число игроков 2/3/4): лорды — контроль 7/5/4 районов;
  Витинари — миньоны в 11/10/9 районах; Дракон — 8 жетонов беспорядка на поле;
  Хризопраз — $50 (деньги + стоимость зданий − займы); Ваймс — конец колоды.

**Прерывания** (Гаспод, Клуб «Новая жизнь», Сьюзен, Игорь, Уоллес Сонки и др.).
Когда действие затрагивает фишку или другого игрока, затронутый игрок получает
стадию реакции (`stages`) с выбором «сыграть карту / пропустить». Запрос
показывается **всегда**, когда защита в принципе возможна, — независимо от того,
есть ли у игрока подходящая карта, иначе по наличию паузы можно вычислить руку.
Против случайных событий прерывания работают только в случаях из FAQ.
Остальные игроки видят «Ждём ответа <имя>…».

**Отмена:** `undo` в пределах своего хода. Ходы со скрытым или случайным
результатом (добор карты, событие, бросок кубика, взятие карты у игрока)
помечаются как неотменяемые; отмена через них невозможна.

**Ручной режим** (активный игрок или игрок в стадии реакции): поставить, убрать,
переместить миньона, здание, беспорядок, демона, тролля; взять или отдать деньги
банку или игроку; взять, сбросить, передать карту. Каждое действие пишется в лог.
Условия победы проверяются и после ручных правок (в начале следующего хода).

## 3. Карты и порядок автоматизации

**Каталоги** (`engine/src/cards/`) — данные, не код:
```ts
{ id: 'mr-bent', deck: 'green', name: 'Мистер Бент', copies: 1,
  symbols: ['scroll', 'playAnother'], image: 'cards/green/mr-bent.webp',
  effect?: 'mrBent' }   // нет effect → свиток разыгрывается вручную
```
Отдельные каталоги для районов (номер, цена, способность), событий и личностей.

**Эффекты** (`engine/src/cards/effects/*.ts`) — по файлу на группу похожих карт.
Единый интерфейс: эффект — последовательность шагов с выборами («выбери игрока»,
«выбери район», «выбери фишку», «выбери карту из руки»); клиент показывает их
подсветкой на поле или списком. Сначала пишутся шаблоны («получи $N с каждого
игрока», «убери миньона в районе», «возьми N карт»), потом уникальные карты.

**Вехи:**
1. **Играбельный каркас:** конвейер ассетов, лобби, поле, подготовка, личности,
   все базовые символы, беспорядки, контроль, условия победы, финальный подсчёт,
   ручной режим для всех свитков, отмена.
2. **Районы и события:** 12 способностей районов и 12 случайных событий
   (Пожар, Наводнение, Землетрясение и т.д.); Малые боги — по FAQ: сначала все
   броски, затем решение о защите.
3. **Прерывания:** Гаспод, Клуб «Новая жизнь», Сьюзен, Игорь, Уоллес Сонки,
   доктор Мосси Лоун.
4. **Свитки пачками:** сначала шаблонные, затем уникальные. Каждая пачка
   выпускается отдельно; нереализованные карты продолжают работать вручную.

## 4. Интерфейс

Экран стола:
```
┌──────────────────────────────────────────┬──────────────────┐
│                                          │ Игроки: цвет, $, │
│   Поле: склеенный скан, SVG-зоны         │ займы, карт в    │
│   районов поверх, фишки — жетоны;        │ руке, районы     │
│   зум и панорама                         ├──────────────────┤
│                                          │ Текущее действие │
│                                          ├──────────────────┤
│                                          │ Лог              │
├──────────────────────────────────────────┴──────────────────┤
│ Рука (наведение — крупно)        │ Личность │ Ручной режим  │
└─────────────────────────────────────────────────────────────┘
```
- Разыгрывание: клик по карте → она крупно в центре, символы подсвечиваются по
  очереди с кнопками «Выполнить» / «Пропустить»; доступные районы и фишки
  подсвечиваются на поле.
- Прерывание: у затронутого игрока окно «Против вас убийство в Тенях — ответить?»
  с подходящими картами из руки и кнопкой «Пропустить».
- Ручной режим: переключатель; клик по району — меню «+/− миньон, беспорядок,
  здание, демон, тролль»; рядом кнопки денег и карт.
- Конец игры: раскрытие личностей и разбивка очков.
- Лобби из «Киклад»: имя, выбор одного из 4 цветов, ссылка-приглашение, старт хостом.

## 5. Тестирование

- **Движок (vitest):** юнит-тесты базовых правил (беспорядки, контроль, соседство,
  размещение, здания, убийство), каждого условия победы и финального подсчёта;
  тест на каждый автоматизированный эффект карты, района и события.
- **Скрытая информация:** `playerView` не отдаёт чужие руки, личности и порядок колод.
- **Отмена:** через неотменяемые ходы откатиться нельзя.
- **Интеграция:** полная партия случайными допустимыми ходами до конца колоды
  без исключений (2, 3 и 4 игрока).
- **Сеть и вёрстка:** `scripts/net-test.mjs` (несколько клиентов через сокеты) и
  `scripts/shot.mjs` (скриншоты puppeteer) из «Киклад».
- **Ассеты:** проверка соответствия каталога и вырезанных картинок.

## Вне рамок

Мобильная вёрстка, сохранение партий между перезапусками сервера, боты,
дополнения к игре, чат (играем с голосовой связью).
