# Автоматизация текстов карт (свитков) — дизайн

Дата: 2026-10-17. Продолжение спецификации `2026-10-17-ankh-morpork-design.md` (веха 4,
выполняется раньше вехи 2 по решению пользователя).

## Цель

Свиток (текст карты) разыгрывается движком: игрок ведётся по шагам с подсказками,
соперник отвечает сам, где карта даёт выбор ему. Ручной режим становится полным набором
действий, чтобы любую ошибку автоматики можно было исправить руками.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Объём | Все 70 свитков, шестью пачками; 6 прерываний (Гаспод, Сьюзан, Игорь, Клуб «Начни заново», Уоллис Сонки, Доктор Лаун) — веха 3, пока вручную |
| Кто отвечает за соперника | Сам соперник, на своём экране (stage `respond`) |
| Устройство движка | Библиотека шагов + короткий сценарий на карту (не JSON-язык и не функция на каждую карту) |
| Отмена | Любой шаг автоматики откатывается, кроме шагов, открывших скрытое или случайное |
| Ручной режим | Расширяется до полного набора действий (см. раздел 4) — делается первым |
| Тексты | Как напечатано на русских картах; где текст неполный или спорный — по оригиналу и FAQ |

## 1. Движок

### Ожидающий выбор

```ts
interface Prompt {
  cardId: string;            // какой свиток разыгрывается
  step: number;              // шаг сценария
  data: Record<string, unknown>; // что уже выбрано (игрок, район, фишка…)
  actor: PlayerID;           // кто отвечает: активный игрок или соперник
  kind: 'player' | 'area' | 'piece' | 'move' | 'hand' | 'choice' | 'reveal';
  options: unknown[];        // допустимые варианты
  min?: number; max?: number; // для выбора нескольких карт
  text: string;              // «Выберите слугу другого игрока»
  reveal?: string[];         // скрытые карты, видимые только actor (playerView)
  locked?: boolean;          // шаг открыл скрытое/случайное: пропуск и отмена недоступны
}
```

`G.prompt: Prompt | null`. Пока он не пуст, текущий символ — свиток, и игра ждёт ответа.

- **Ход `answer(choice)`.** Проверяет, что отвечает `actor`, и что `choice` входит в `options`
  (для `hand` — от `min` до `max` карт из руки `actor`). Затем продвигает сценарий.
  Если отвечает не активный игрок, ему через `setActivePlayers({ value: { [actor]: 'respond' } })`
  открывается стадия `respond`. Ход `answer` разрешён в ней; по завершении ответа
  управление возвращается активному игроку.
- **Ход `skipScroll()`.** Прерывает сценарий (свиток по правилам необязателен).
  Недоступен при `locked`.
- **Шаги, открывающие скрытое или случайное** (добор/показ карт, бросок кубика, случайная
  карта у игрока, перемешивание сброса, смена личности) выполняются ходами
  `{ client: false, undoable: false }` и ставят `locked`.
- **`playerView`.** Скрывает `prompt.reveal` от всех, кроме `prompt.actor`. Руки
  соперников по-прежнему скрыты.

### Библиотека шагов (`engine/src/cards/steps.ts`)

| Шаг | Что делает |
|---|---|
| `choosePlayer(filter)` | выбор другого игрока (фильтр: «есть карты», «есть здание», «не я»…) |
| `chooseArea(filter)` | выбор района (соседний с …, с беспорядком, со своим зданием, Внедвижимость или соседний…) |
| `choosePiece(filter)` | выбор фишки в районе: чей слуга, демон, тролль, здание |
| `moveTo(filter)` | район-цель для перемещения выбранной фишки (по общим правилам беспорядков) |
| `chooseHand(min, max)` | выбор карт из своей руки |
| `ask(player, options)` | вопрос сопернику с кнопками («Заплатить $5» / «Взять карту») |
| `reveal(cards)` | показать скрытые карты actor (и, при необходимости, выбрать одну) |
| `roll()` | бросок d12 с записью в лог |

Готовые операции над состоянием переиспользуются из `rules.ts` и `manual.ts`
(постановка и снятие фишек с учётом беспорядков, перевод денег, перемещение карт).

### Сценарии (`engine/src/cards/effects/*.ts`)

Эффект — функция `(G, ctx, prompt-ответ) → следующий Prompt | готово`, собранная из шагов.
Похожие карты делят один сценарий с параметрами (например, `moveOtherMinionAdjacent`
для Утки, Старикашки Рона и Подмостовной братии). Каталог: `cardId → { effect, params }`.
Карта без записи в каталоге по-прежнему разыгрывается вручную.

### Зона «перед игроком»

`players[pid].front: string[]` — карты, лежащие перед игроком, видимые всем.
- Банк Анк-Морпорка и Мистер Бент: карта кладётся в `front`, +$10 и +1 займ.
- Гильдия шутов и Доктор Белолицый: кладутся в `front` выбранному игроку. Такая карта
  занимает место при доборе до пяти (`HAND_SIZE − их число`), сбросить её нельзя.
- Финальный подсчёт и Хризопраз по-прежнему считают займы через `loans`.

### Модификатор хода

Крошка Безумный Артур строит здание за полцены. Это шаг сценария, а не флаг: «выберите район
для здания», стоимость `ceil(cost / 2)`, остальные правила постройки обычные.

## 2. Интерфейс

- **Плашка подсказки** над полем по центру, крупно: название карты, текст шага, кнопки
  «Готово» (для выбора нескольких) и «Пропустить» (если не `locked`).
- **Район:** подсвечены допустимые районы, клик выбирает.
- **Фишка:** клик по району → всплывашка с фишками района, доступные активны.
  При перемещении затем подсвечиваются районы-цели.
- **Игрок:** в плашке кнопки игроков их цветом, недоступные серые. Карточки игроков в
  правой панели тоже кликабельны.
- **Карты из руки:** рука выдвигается сама, карты отмечаются галочкой, счётчик
  «выбрано N из M», кнопка «Готово».
- **Ответ соперника:** у `actor` модальное окно поверх всего: карта целиком, кто её сыграл,
  варианты, при необходимости — его рука с выбором карт. В хотсите сначала заглушка
  «Отвечает Игрок 2 — передайте ему компьютер» и кнопка «Я Игрок 2, показать».
  Остальные видят в плашке «Ждём ответа Игрока 2…».
- **Показ скрытого:** модальное окно только у `actor` (рука соперника, неиспользованные
  личности) с кнопкой «Понятно» или выбором карты.
- **Кубик:** короткая анимация, в плашке результат и его следствие.
- **Без выбора:** применяется сразу, результат пишется в лог («Отто Шрик: +$5 за 5 беспорядков»).
- **Зона «перед игроком»:** миниатюры в карточке игрока, при наведении — крупно.

## 3. Отмена

- «↶ Отменить» откатывает любой шаг автоматики внутри хода, включая сам розыгрыш карты
  (карта возвращается в руку).
- Шаги с `locked` (скрытое или случайное) откатить нельзя: кнопка неактивна с подсказкой
  «Исправьте вручную ✋». Откат возможен только до такого шага.

## 4. Ручной режим — полный набор действий

Делается первым, как страховка. Каждое действие пишется в лог с ✋.

| Область | Действия |
|---|---|
| Фишки | поставить, убрать, **перетащить с района на район** (слуги, здания, демоны, тролли, беспорядки) |
| Деньги | банк ↔ игрок ↔ игрок; займы ± (есть) |
| Карты | переложить карту между зонами: своя рука, верх/низ колоды, сброс (любая карта), «перед игроком» (своя или чужая), рука соперника (отдать; взять случайную); разыгрываемую карту — вернуть в руку или отдать игроку (есть) |
| События | вернуть вытянутое событие в колоду (наверх или перемешав), убрать событие из игры |
| Личности | поменять свою на случайную неиспользованную; посмотреть неиспользованные (только себе) |
| Ход | +1 к «можно сыграть карту», закончить ход без добора, объявить конец игры (подсчёт очков или победитель вручную) |
| Кубик | бросить d12, результат в лог |

Скрытое в ручном режиме не открывается другим: взятая случайная карта видна только
получателю, просмотр неиспользованных личностей — только себе.

## 6. Тестирование

- **Шаги:** юнит-тесты каждого шага (валидация вариантов, отказ на чужой `actor`, `locked`).
- **Карты:** по тесту на каждую автоматизированную карту — успешный розыгрыш и пропуск.
- **Ответ соперника:** через `Client` boardgame.io — стадия `respond`, ответ только от `actor`.
- **Скрытое:** `playerView` не отдаёт `reveal` никому, кроме `actor`; `scripts/secrecy-test.mjs`
  дополняется розыгрышем Особистов.
- **Отмена:** откат шага автоматики; невозможность отката `locked`-шага.
- **Ручной режим:** тест на каждое новое действие.
- **Автопартии:** бот из `game.test.ts` отвечает на любые `prompt` случайным допустимым
  вариантом; 9 партий доходят до конца.
- **Браузер:** `scripts/hotseat-test.mjs` разыгрывает по карте каждого типа шага.
